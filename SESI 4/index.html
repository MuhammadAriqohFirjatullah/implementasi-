INTRODUCTION TO MACHINE LEARNING

Belajar dari data,
mengenali pola.

Machine Learning (ML) memungkinkan komputer mempelajari pola dari data untuk membuat prediksi atau mengelompokkan informasi.

Coba simulasi ↓
01

Supervised Learning

Belajar dari data yang memiliki label untuk memprediksi hasil, misalnya memperkirakan harga rumah.

02

Unsupervised Learning

Mencari pola atau kelompok pada data tanpa label, misalnya mengelompokkan pelanggan.

03

Reinforcement Learning

Belajar melalui tindakan dan umpan balik berupa reward atau penalti.
